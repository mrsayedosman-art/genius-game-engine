# Combustion scene atlas

Generated using the built-in ImageGen tool for Lesson 2.

Prompt: Create six distinct educational game scenes in a two-column,
three-row atlas with no lettering: dry and wet paper near a candle; blue and
yellow Bunsen burner flames with soot; burning magnesium with white ash;
rice straw burning and dark smoke; traffic exhaust and an electric bus;
a factory gas scrubber. Consistent clear educational illustration style,
navy/teal/amber palette, visible scientific distinctions at mobile sizes.

The atlas is an illustrative depiction. Labels, equations, answer keys and
the burner simulation are implemented separately in accessible HTML.
