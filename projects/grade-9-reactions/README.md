# Grade 9 Reaction Lab

Nine independent four-challenge games for Lesson 1, Types of Chemical Reactions.

- Direct combination and decomposition.
- Single replacement: dilute acid, water, and salt solution.
- Double replacement: neutralization, acid with carbonate, and precipitation.
- Oxidation and reduction.

Entry point: `index.html`. Each mission supports a direct `?game=` link.
No build, third-party library or internet connection is needed. Open the main
hub with a static web server or the existing GitHub Pages deployment.

The activities were authored from the supplied reference:
`D:\hard contents\حلقاتي ع اليوتيوب\g9\2027\DOC-20260927-WA0042.pdf`,
Lesson 1, PDF pages 13–36. Equations and observations were checked against
the lesson; questions are original activities, not copied question-bank text.
The reference remains outside the public repository.

All interactions use buttons suitable for touch, mouse and keyboard.
Scores award 3 points on the first correct attempt, 2 on the second and 1
thereafter. Hints are free. The best score is saved locally on the device
when browser storage is available; this is not a teacher dashboard.
