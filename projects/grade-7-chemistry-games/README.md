# Genius Chemistry Games — Grade 7

Interactive games based on the supplied Grade 7 chemistry worksheets, branded for **Mr. Elsayed Osman / Genius in Science**.

## Start the classroom game

1. Double-click `start-classroom.bat`, or run `npm start` in this folder.
2. Keep the terminal window open during the activity.
3. Share the **Classroom network** address printed in the terminal with students connected to the same Wi-Fi.
4. Open the teacher dashboard at `http://localhost:8080/?view=teacher`.

Students appear immediately after entering their names. The dashboard updates score, current mission, time, and status live. Ranking is sorted by highest score first, then shortest time.

No package installation or internet connection is required.
